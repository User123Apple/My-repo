# Radio ZET HLS — Blitz.cloud

Ustawienia Blitz:
- Dockerfile: `Dockerfile`
- Start command: `/app/start.sh`
- Port: `8080`
- Run in the background: wyłączone

Wynik HLS:
`/live/radiozet.m3u8`

Adres będzie miał postać:
`https://TWOJ-ADRES.blitz.cloud/live/radiozet.m3u8`

Źródło audio należy retransmitować wyłącznie wtedy, gdy masz odpowiednie prawa.
